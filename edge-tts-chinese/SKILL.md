# 中文文字转语音

使用随技能提供的 `scripts/tts.py`，不需要 API Key。将下方 `<skill-dir>` 替换为本技能实际目录；不要假定技能安装在某个用户的绝对路径。

## 默认选择与范围

- 默认 `zh-CN-YunjianNeural`（云健男声）、语速 `-10%`；用户指定的音色和语速优先。
- 可选 `xiaoxiao`（晓晓女声）、`yunxi`（云希男声）、`yunjian`（云健男声），也接受完整 Voice ID。声音风格随文案变化，不能把名称当作试听结论。
- 保持用户原文。读音不确定时先用短句验证，尤其是项目名、多音字、数字、英文、URL、文件名和命令；需要调整口播写法时说明调整内容。
- 按当前用户和项目的确认规则执行；已经确认的音色与范围不重复询问。用户只要求样音时，不替换完整视频。
- Edge TTS 使用 Edge 的在线朗读服务和第三方开源客户端，不是 Azure 正式 API；服务可用性及使用条款由微软决定。需要官方服务授权或稳定承诺时另选供应商，不把“无需密钥”表述为商用授权。

## 环境准备

需要 Python 3.9 或更新版本和网络。首次运行：

```bash
python3 "<skill-dir>/scripts/tts.py" --setup
```

脚本在技能自己的 `.venv/` 中安装固定版本 `edge-tts==7.3.1`，不会安装到系统 Python。可通过 `EDGE_TTS_CHINESE_VENV` 指向另一个独立环境；已安装的环境会复用。环境无需随技能压缩包分发。

## 合成与字幕

直接输入文字：

```bash
python3 "<skill-dir>/scripts/tts.py" \
  --text "这是颐养通，让社区养老服务的每一笔记录清楚可查。" \
  --output "/absolute/output/旁白.mp3" \
  --subtitles "/absolute/output/旁白.srt"
```

读取 UTF-8 文本文件，或换音色、语速、音量与音高：

```bash
python3 "<skill-dir>/scripts/tts.py" \
  --file "/absolute/input/旁白.txt" \
  --voice xiaoxiao --rate=-5% --volume=+0% --pitch=+0Hz \
  --output "/absolute/output/晓晓.mp3"
```

**负数参数必须用等号**，例如 `--rate=-10%`，不要写成 `--rate -10%`。可用 `--timeout 180` 延长单次合成的总时限，默认 120 秒。需要代理时显式传 `--proxy "http://127.0.0.1:端口"`。

查询当前可用中文声音（也需要联网）：

```bash
python3 "<skill-dir>/scripts/tts.py" --list-voices
```

同一文案、相同语速可生成多条样音。默认不覆盖已有输出；只有用户已授权替换时使用 `--overwrite`。MP3 与 SRT 先暂存并校验非空，合成失败不发布半成品。成功后脚本输出包含实际音色、语速、路径和字节数的 JSON。

## 视频旁白衔接

用户要求替换视频配音时，先检查原项目如何保存文案和分镜，保留既定画面与文案范围。静态分镜按新音频的实际时长重排，已有动态画面则先明确时长适配；不要盲目将新音轨截短或循环来凑原长度。

每个分镜可单独生成 MP3 与句级 SRT。合片时，字幕时间必须加上分镜在最终片中的起点及人为添加的音频延迟，并使用实际编码后的分镜时长累计，避免逐段漂移。此技能不自动修改视频或重打包项目。

## 核验与失败处理

- SRT 来自 Edge 的句级时间边界，不是 `Communicate.save()` 的 JSON 元数据，也不是按字数估算时间。
- Edge 原始 MP3 为 24 kHz、单声道、约 48 kbps；转为 AAC、立体声或更高采样率不会提升原始音质。
- 有 `ffprobe` 时检查音频能解析、时长大于零；有字幕时检查时间递增、最后一条不明显超出音频。听感交给用户试听，不把格式核验说成已试听。
- 失败后根据明确原因最多修正并重试一次；仍失败就保留有效结果并报告原因与可行下一步。不要无限重试、切换多个镜像反复安装、关闭 TLS 校验或擅自改用付费服务。
- 交付音频时提供可点击路径；在支持本地音频预览的客户端中，可用 `![音频](/absolute/path/旁白.mp3)` 供用户试听。
