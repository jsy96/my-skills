# 口播稿与 Vox Director Handoff

## 口播稿合同

时长 30—60 秒，结构固定：

1. **钩子**：前 3 秒抛问题、反常识判断或结论
2. **场景**：一个具体使用场景或真实困扰
3. **判断**：指出真正问题
4. **解法**：给出做法、路径或工作流
5. **结尾**：收束成一个记忆点或行动提醒

写法：

- 短句、口语化、可直接念
- 每句承担一个信息增量
- 不写舞台说明和抽象口号
- 保留真实体验，不承诺普遍效果
- 若时长未实测，标明为预估，待真实旁白生成后校正

## Vox 逐镜头脚本

输出表格，列包括：

- 时间区间
- 段落
- 画面
- 字幕
- 口播旁白
- 动作
- 声音

要求：

- 视觉统一为纸贴 / 拼贴 / 剪纸风格
- 相邻镜头变化景别或运动，避免连续静态同构
- 每 3—5 秒有视觉变化
- 提示词只描述动作和环境音
- 禁止在视频提示词中请求背景音乐、对白或旁白
- 旁白与视频提示分开管理

## 生产硬规则

必须遵守：

1. 先生成真实旁白，再根据实测音频长度安排镜头
2. 开始阶段推荐 3 个标题和 4 款同场景视觉样章，由人工统一确认
3. 剪纸 / 纸贴是固定媒介，配色、版式和视觉隐喻根据选题变化
4. 标题和风格未确认前，不批量生成关键帧，不调用付费视频 API
5. 视频 API 最多同时运行两个任务
6. 每次付费调用前给出费用预估，支持状态轮询、自动下载和断点继续
7. 平台固定 5 / 10 秒素材时，根据真实动作和旁白决定裁剪或变速
8. 合成时默认保留确认过的平台动作音效，不额外添加背景音乐
9. 开头增加 3—4 秒静态纸贴封面，旁白从封面结束后开始
10. 封面必须独立重新构图，不能只在第一帧覆盖大矩形文字框
11. 布尔配置必须按布尔值处理，不能渲染成水印文字
12. 最终交付同时输出标题、简短发布文案和标签

## 分镜预排模板

| 时间 | 段落 | 画面 | 字幕 | 口播旁白 | 动作 | 声音 |
|---|---|---|---|---|---|---|

分镜建议：

- 00:00—00:03：独立封面，无旁白
- 00:03—00:07：钩子
- 00:07—00:16：场景与细节
- 00:16—00:21：判断
- 00:21—00:33：解法与路径
- 00:33—00:38：结果或归档
- 00:38—00:45：结尾记忆点

真实旁白生成后，重新按每段实测时长微调，不直接按文字长度定稿。
