# 平台内容合同

## 素材学习

先从用户素材中提取：

- 目标读者与使用场景
- 核心判断
- 真实案例、动作和结果
- 方法步骤、限制条件
- 作者语气：短句 / 举例 / 自嘲 / 判断句 / 常用词
- 可复用资产：金句、结构图、截图、数据、案例、标签

不要把讲义或会议纪要直接当成成品文章。先重组为读者任务，再输出成稿。

## 公众号文章

交付顺序：

1. 目标读者
2. 核心观点
3. 3 个标题
4. 结构骨架
5. 初稿
6. 配图建议
7. 审稿清单

写作要求：

- 开头进入具体场景或问题，不做空泛背景铺垫
- 每节有信息增量：案例、判断、步骤、代价或边界
- 保留个人语气和真实细节
- 不过度承诺效果，不把一次体验写成普遍规律
- 图注与正文互相支撑，图片不是装饰
- 审稿清单包含：事实、结构、语气、标题兑现、配图一致性、占位符、平台边界

## 小红书图文

交付清单：

1. 3 个标题
2. 一句开场钩子
3. 短段落正文
4. 3:4 封面标题
5. 6 张配图，每张包含画面与文案
6. 标签

写作要求：

- 一篇只解决一个主要问题
- 开场钩子来自真实痛点，不制造焦虑
- 正文短句、口语化、可直接手机阅读
- 不夸张承诺；体验类内容写本人观察和适用边界
- 六张图按叙事推进：痛点 → 解法 → 结构 → 场景 → 机制 → 资产 / 结果
- 标签少而相关，不复读关键词

生成流程：

1. 先输出完整图文方案，等待确认
2. 确认后生成 7 张 1200×1600 图片：1 张封面 + 6 张正文图
3. 保存到独立目录
4. 写入新飞书文档并回查 7 张图片
5. 缺素材处明确 `[待补]`

## 多风格重制

用户要求换风格时：

- 保留已确认文案和信息结构
- 只替换视觉系统
- 新建资产目录，例如 `assets/<topic>-<style>/`
- 新建飞书文档，标题中注明风格版本
- 不修改原文档
- 文档开头增加简短「视觉版本说明」，说明新风格的关键元素
- 回查新文档图片数量与文案完整性

可复用风格方向：

- 小黑手绘：白底、黑色线条、红橙蓝批注、怪诞隐喻
- 现代杂志纸贴：米白底、撕纸边缘、胶带、半网点、墨蓝 / 橙红
- 手绘涂鸦：白纸底、黑色手绘线条、黄色荧光笔、蓝红涂鸦
- Vox 纸贴拼贴：剪纸、胶带、报纸碎片、大字标题、大胆平色

## 通用审稿

交付前检查：

- 标题承诺是否被正文兑现
- 是否保留真实案例与个人语气
- 是否存在编造事实、夸张收益、虚构用户反馈
- 每个占位符是否必要且清楚
- 图文数量和顺序是否正确
- 手机端是否易扫读
- 结尾是否给出自然记忆点或下一步
